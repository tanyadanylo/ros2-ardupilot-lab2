# Лабораторна робота №2 — Автономний політ БПЛА

Навчальний проєкт з автономного керування квадрокоптером Iris у симуляційному середовищі Gazebo з використанням ROS 2 та ArduPilot SITL.

## Завдання — варіант №6

Реалізувати автоматичний зліт, переміщення квадрокоптера від початкової позиції на задане зміщення та автоматичну посадку.

- Задане зміщення: Δx = 8,2 м; Δy = 0,2 м.
- Ціль у системі координат симуляції: x = −8,2 м; y = −0,2 м.
- Допустима похибка позиціювання: 0,2–0,3 м.

## Алгоритм польоту

1. Перевірка готовності ArduPilot.
2. Перехід у режим GUIDED та активація двигунів.
3. Зліт на висоту 4 м і стабілізація.
4. Переміщення до цільової точки над стінами лабіринту.
5. Перехід у режим LAND та автоматична посадка.
6. Обчислення кінцевої похибки позиціювання.

## Результати моделювання

| Показник | Значення |
|---|---|
| Висота після зльоту | 4,04 м |
| Цільові координати | (−8,20; −0,20) м |
| Кінцеві координати | (−8,10; −0,19) м |
| Кінцева похибка | 0,103 м |
| Результат | Успішне виконання |

## Технології

- Python
- ROS 2 Humble
- ArduPilot SITL
- Gazebo
- DDS

## Структура проєкту

- `fpv_lab2/` — ROS 2-пакет із програмами керування польотом.
- `worlds/iris_maze_lab2.sdf` — файл світу Gazebo з лабіринтом та моделлю Iris.
- `start_lab2_maze.sh` — скрипт автоматизованого запуску.

## Примітка

Для запуску потрібне попередньо налаштоване середовище ROS 2, ArduPilot SITL, Gazebo та відповідні моделі й плагіни ArduPilot Gazebo. Скрипт використовує шляхи локального навчального середовища.

Проєкт створено для виконання університетської лабораторної роботи.

## Запуск і зупинка симуляції

Для роботи потрібне попередньо налаштоване середовище ROS 2 Humble, Gazebo та ArduPilot SITL.

**Запуск лабораторної (варіант №6):**

`~/fpv_labs/start_lab2_maze.sh variant6`

**Зупинка симуляції:**

`~/fpv_labs/stop_lab2.sh`

Скрипт запуску автоматично запускає Gazebo, ArduPilot та програму автономного польоту. Скрипт зупинки завершує процеси симуляції.
